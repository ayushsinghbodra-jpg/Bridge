📨 Message Send Flow

User types in MessageInput component
useMessages hook calls send()
messageService.sendMessage() API call
MessageController handles POST request
MessageService.send() validates & saves to DB
ChatGateway emits "message:new" to channel
useSocket receives message via socket
messageStore.addMessage() updates state
MessageList re-renders with new message
